# MarkFlow — Markdown to HTML Converter



**MarkFlow** is a sleek, browser-based Markdown to HTML converter built with vanilla JavaScript. It provides real-time conversion of common Markdown syntax into clean HTML, with both raw HTML output and a live preview side-by-side.

## ✨ Features

- **Real-time Conversion** — Type Markdown on the left, see HTML and preview update instantly
- **Comprehensive Markdown Support**:
  - Headings (H1, H2, H3) using `#`, `##`, `###`
  - Bold text using `**bold**` or `__bold__`
  - Italic text using `*italic*` or `_italic_`
  - Images with `![alt](src)`
  - Links with `[text](url)`
  - Blockquotes using `> quote`
- **Raw HTML Output** — View the generated HTML code in a syntax-highlighted dark theme display
- **Live Preview** — See rendered HTML rendered in real-time
- **Responsive Design** — Works beautifully on desktop and mobile devices
- **No Dependencies** — Pure HTML, CSS, and JavaScript
- **Glassmorphism UI** — Modern, polished aesthetic with blur effects

## 🛠️ Tech Stack

- HTML5
- CSS3 (Glassmorphism, Flexbox, Grid)
- Vanilla JavaScript (ES6)
- Regular Expressions for Markdown parsing
